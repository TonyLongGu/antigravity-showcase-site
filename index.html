極速上手

兩種安裝方式 • 輕鬆無縫部署

支援「下載 ZIP 點擊安裝」與「Git Clone + AI Agent 自動化協同」雙路徑，自由選擇一鍵全安裝或個別插件自選啟用。

01 下載全套套件包並解壓縮

點擊下方按鈕下載最新版全套套件 ZIP，並解壓縮至本機任意目錄（例如 D:\antigravity-plugins）：

📦 下載全套插件包 (.zip) 無需 Git 環境 • 解壓即用

02 執行安裝腳本（一鍵全安裝 或 單獨安裝）

一鍵安裝全部插件
雙擊執行腳本

雙擊專案根目錄下的「雙擊一鍵安裝.bat」，腳本將自動以目前解壓目錄為路徑基底，一次性批次為 6 大擴充套件建立免編譯掛載：

.\雙擊一鍵安裝.bat
單獨安裝特定插件
進入插件目錄執行

進入欲啟用的插件目錄（例如 antigravity-toolbox/），雙擊該目錄下的「install-extension.bat」即可單獨啟用：

<插件名稱>/install-extension.bat

03 重新載入 Antigravity IDE 視窗

重新啟動 IDE，或是在 IDE 中按快捷鍵 Ctrl + Shift + P，輸入並執行 Developer: Reload Window 即可立即在側邊欄與狀態列看到全新擴充功能！

01 複製 AI 智能安裝提示詞

點擊下方按鈕複製結構化安裝 Prompt，提示詞內建 GitHub 倉庫來源與全流程對話引導：

Antigravity AI Interactive Installer
“ 請幫我從 GitHub (https://github.com/TonyLongGu/antigravity-plugins.git) 安裝 Antigravity IDE 原生擴充套件。

請依序執行以下引導流程：
1. 先詢問我要安裝哪些套件（提供選項：一鍵安裝全部 6 大套件，或自選個別套件）。
2. 詢問我希望將專案原始碼 Clone/放置在本機的哪個目錄（提供預設建議路徑，如 D:\antigravity-plugins）。
3. 根據我的回覆，自動在該目錄執行 Git Clone，並自動為選定的套件建立 IDE 擴充功能掛載。
4. 安裝完成後，提醒我重新載入視窗 (Developer: Reload Window)。 ”
零終端機操作 • AI 互動引導

02 貼入 Antigravity AI Chat 對話框

在 Antigravity IDE 任意視窗打開 AI Chat 對話框，貼上剛剛複製的提示詞並發送。

03 跟隨 AI 引導並全自動安裝

AI Agent 將主動向您確認安裝項目與本機目錄，隨後全自動完成 Git Clone 與軟連結掛載：

步驟 A AI 主動詢問：安裝【全套 6 大插件】還是【自選特定套件】？
步驟 B AI 主動詢問：希望將專案安裝在本機哪個資料夾？（預設建議 D:\antigravity-plugins）
步驟 C AI 自動執行：背景 Clone 倉庫 ➔ 建立 Junction 軟連結 ➔ 引導重載視窗即刻生效！

Windows Junction 免編譯技術

以原生目錄連接點掛載至 Antigravity 擴充目錄，零磁碟重複空間，修改代碼即時熱生效。

無痕卸載安全無殘留

隨時雙擊「雙擊一鍵解除安裝.bat」或個別目錄下的「uninstall-extension.bat」秒級乾淨卸載。
