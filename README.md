# Antigravity IDE Plugins 展示網站 (GitHub Pages)

本目錄為 Antigravity IDE 原生擴充套件生態之靜態展示網站，可直接透過 **GitHub Pages** 託管上線。

---

## 🚀 GitHub Pages 一鍵發布步驟

1. 將本專案 Push 至 GitHub 倉庫（如 `https://github.com/TonyLongGu/antigravity-plugins`）。
2. 進入該 GitHub 倉庫頁面，點擊上方 **Settings**（設定）。
3. 在左側選單點擊 **Pages**。
4. 在 **Build and deployment** 區塊：
   - **Source** 選擇 `Deploy from a branch`
   - **Branch** 選擇 `main` 分支，資料夾下拉選單選擇 **`/docs`**
   - 點擊 **Save**
5. 等待 1~2 分鐘，即可在頂部看見上線網址（例如：`https://tonylonggu.github.io/antigravity-plugins/`）！

---

## 💻 本機預覽方式

直接以瀏覽器雙擊開啟 [`index.html`](./index.html) 或使用 VS Code / Antigravity Live Server 預覽。
